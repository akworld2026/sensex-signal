Read before acting: this tool classifies the market's current position relative to its own recent history — it does not predict future returns. Zone shifts should change where fresh SIP money goes, never trigger selling existing units (that creates avoidable LTCG/STCG tax drag, as discussed earlier). The required XIRR shown above is only as reliable as the assumed return you set in the SIP calculator, and it gets steeper if early months underperform — which is exactly what the revalidation panel is for. Treat every output here as a planning input, not a guarantee — small/mid-cap-heavy portfolios carry real drawdown risk that no allocation formula removes.
